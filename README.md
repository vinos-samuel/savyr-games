# Savyr's Game Lab

My son and I build small browser games together. He designs, I drive the keyboard, and an AI coding agent does the heavy lifting. Each game starts as a one-page game card written in his words and ends as something he can actually play.

## Games
| # | Game | Idea |
|---|------|------|
| 00 | Orientation | "Meet your builder" — how we work together |
| 01 | Marble Catapult | Pull back, launch a marble at a hoop, win money that doubles each round, merge marbles into stronger ones. Every 5th round a boxing glove guards the hoop. |

Bigger finished game: [Crit-terror](https://github.com/vinos-samuel/crit-terror), a brick tower-defense game.

## How a session works
1. Interview: what's the game, who's the hero, how do you win?
2. Write it down as a `GAME_CARD.md`.
3. Build the smallest playable version, play it, change one thing, repeat.

## Run it
Each game is a static page. Open `NN-game-name/index.html` in a browser.

## Why
To show a kid that software is something you make, not just something you use.
